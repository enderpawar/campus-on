# 캠퍼스 온 화면 명세 보드

2026-11-06 목업 기준. 팀 회의에서 화면을 함께 보거나 메신저로 이미지 명세서를 전달하기 위한 자료다. 실제 학교 계정·AI·신청 서비스와 연결되지 않은 예시 화면이다.

## 보는 방법

1. `index.html`을 브라우저에서 연다. 저장소의 정적 서버를 사용한다면 `http://127.0.0.1:4180/docs/review/`로 접속한다.
2. 왼쪽 화면 목록에서 화면을 고르고, 화면·상태 선택으로 데스크톱·모바일·세부 상태를 바꾼다.
3. 이미지를 누르면 확대해서 볼 수 있다. 화면별 명세 PNG와 원본 캡처는 갤러리의 다운로드 링크로 저장한다.

갤러리는 외부 CDN이나 API를 사용하지 않는다. 인터넷 없이도 열 수 있으며, 글꼴과 이미지는 함께 배포된 상대 경로를 유지해야 한다.

## 포함된 화면과 상태

- 공통: 알림 팝오버, 프로필 팝오버, 모바일 알림.
- 홈·학습·복지·취업: 데스크톱과 모바일 전체 화면.
- 일정: 기본 화면, 일정이 없는 날짜, 모두 완료, 모바일.
- 학교 소식: 전체 목록, 장학 필터, 모바일.
- 테크뇽: 프로그램 추천, 자료 기반 예시 질문·답변, 모바일.
- 대화상자: 일정 추가, 수업 상세, 모바일 일정 추가.
- 학습 자료: PDF 예시와 요약, 핵심 개념, 퀴즈 답 선택 후 해설, 플래시카드 뒷면, 영상, 요약 중, 요약 실패, 모바일.

## 캡처 기준

- 원본 캡처 30장: 데스크톱 1440×1000, 모바일 390×844 CSS px, 배율 1.
- 주요 화면은 페이지 전체 길이를 저장했다. 팝오버·테크뇽·대화상자는 열린 위치가 보이도록 화면 높이만 저장했다.
- 브라우저의 동작 줄이기를 적용해 전환 애니메이션 중간 프레임을 피했다.
- 캡처는 실제 목업의 메뉴·버튼을 조작해 만들었다. 설명을 위해 화면 내용을 합성하거나 학교 서비스와 연결하지 않았다.
- PNG 명세 보드는 폭 2200px이며 화면 내용에 따라 높이가 다르다. 모바일·추가 상태의 보드 미리보기와 전체 원본 캡처를 구분한다.

## 팀에 전달하기

저장소 루트의 `campus-on-screen-specs.zip`을 전달한다. 압축을 풀고 `docs/review/index.html`을 열면 된다. 이 압축파일에는 갤러리, PNG 명세 보드, 원본 캡처, 기존 화면별 Markdown 명세 및 필요한 글꼴·목업 파일이 포함된다.

이미지만 전달할 때는 `boards/`의 PNG 9장을 사용한다. `index.html` 파일 하나만 전달하면 이미지·글꼴이 빠지므로 압축파일이나 관련 폴더 전체를 전달한다.

## 편집 및 갱신

- `screens.js`: 화면별 문구와 캡처 매핑.
- `index.html`, `review.css`, `review.js`: 갤러리와 이미지 보드 레이아웃.
- 기존 상세 명세는 `../screens/00-공통.md`부터 `08-학습-자료.md`까지 유지한다.
- `?board=home`처럼 화면 ID를 지정하면 PNG로 내보내기 위한 고정폭 보드가 열린다. 각 화면 ID는 위 PNG 파일명과 같다.
- 목업이 바뀌면 해당 캡처를 다시 저장하고, 보드 페이지의 이미지·글꼴 로드가 끝난 후 `#spec-board` 전체를 PNG로 캡처한다. 마지막에 공유 압축파일도 갱신한다.

PDF 영역은 실제 PDF 파일을 읽는 뷰어가 아니라 HTML 예시 슬라이드다. 요약·퀴즈·답변과 추천·마감 정보는 예시이며, 서버 저장·학교 계정 연동·실제 AI 생성은 이 공유 자료의 구현 범위가 아니다.
